# AI Agent Project

## Overview
This is a Python-based backend project that handles server-side processing and integrates with external APIs to extract and process data. The project focuses on backend logic rather than UI.

## Features
- Backend logic written in Python
- API integration using environment variables
- Data processing and structured output generation
- Dashboard-based execution

## Tech Stack
- Python
- Streamlit / Flask
- External APIs

## How to Run
1. Clone the repository  
   git clone https://github.com/Hansika5/AI_Agent_Project.git

2. Install dependencies  
   pip install -r requirements.txt

3. Add environment variables  
   Create a `.env` file and add required API keys

4. Run the application  
   python dashboard.py

## Backend Focus
This project demonstrates backend development concepts such as API handling, environment configuration, data processing, and application execution logic.
